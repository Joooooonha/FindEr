# 아키텍처

## 시스템 구성

```
[사용자 브라우저]
      │
      ▼
[Frontend] ──── Kakao Maps SDK
      │
      ▼ REST API
[Spring Boot - EC2]
      │
      ├── MySQL (응급 카드 데이터)
      │
      └── E-Gen API (공공데이터포털)
            ├── 응급의료기관 기본정보
            └── 실시간 가용병상 정보
```

## 데이터 흐름

### 응급실 탐색
1. 사용자 위치 좌표 → 프론트에서 백엔드로 전달
2. 백엔드 → E-Gen API 호출 (반경 내 기관 목록)
3. 거리 계산 + 가용 상태 점수화
4. 정렬된 병원 목록 응답
5. 프론트 → Kakao Maps에 핀 렌더링

### 응급 카드
1. 사용자 정보 입력 → 백엔드 저장 (MySQL)
2. 고유 토큰 발급
3. `/card/{token}` 공개 URL + QR 코드 생성

## E-Gen API 캐싱 전략

- 기본정보(병원명, 위치, 진료과): 1시간 캐시
- 실시간 가용병상: 캐시 없음 (매 요청마다 호출)
- API 미승인 기간: 기본정보만으로 서비스, 가용병상은 "정보 없음" 표시
